ROMChat — Help & FAQ

Answers to common questions about getting started.

New here? ROMChat is your internal AI assistant for everyday work — drafting, summarizing, analysis, answering questions, and more. This page covers the common questions. If you're ever stuck, you can also just ask the assistant directly in a chat.

Is it safe to put sensitive information in?

Yes. ROMChat runs on ROMTech's approved, secure infrastructure — it's built for confidential and sensitive work. You should use it instead of public tools like ChatGPT or Claude for anything confidential, because those public tools are not approved for ROMTech information.

What can ROMChat help me with?

  • Drafting emails, documents, reports, and templates
  • Summarizing documents, meeting notes, and long content
  • Analyzing and reviewing information
  • Answering general business and technical questions
  • Translating between languages
  • Writing, reviewing, and explaining code
  • Creating simple diagrams, web pages, and code you can preview (see below)

How do I ask questions about a document?

To have the assistant read a file and answer questions about it, use File Search:

  1. Click the tools button next to the message box and switch on File Search.
  2. Click the paperclip and choose Upload for File Search.
  3. Pick your file (PDF, Word, PowerPoint, Excel, or plain text).
  4. Type your question about the document and send.
Tip: turn on File Search before you upload. File Search covers the documents you've added in this conversation.

What's the difference between the upload options?

When you attach a file you may see a few choices. Here's when to use each:

  • Upload for File Search — recommended for documents
    Works with PDF, Word, PowerPoint, Excel, and text files. The assistant reads your file and pulls out the parts relevant to your question — best for most documents, including long ones.
  • Upload as Text
    Pulls the text out of a document (such as a PDF, Word, or text file) and adds it straight into your message. Good for shorter documents you want the assistant to see in full.
  • Upload to Provider
    This option only accepts images and PDFs — it can't be used for Word, Excel, or text files. On ROMChat you won't need it: images aren't supported, and PDFs work better with the two options above. For any document, use Upload for File Search or Upload as Text.

Bottom line: for documents, choose Upload for File Search.

What kinds of files can I upload?

Supported: PDF, Word, PowerPoint, Excel, and plain-text files.

Not supported: images and photos (JPG, PNG, etc.).

I uploaded a document but it didn't seem to read it

  • Make sure File Search is turned on before uploading (step 1 above).
  • When attaching, choose “Upload for File Search.”
  • Scanned or photo-based PDFs (no selectable text) may not be readable.

Which model should I use — Fast or Standard?

ROMChat Fast

The default. Quick and great for everyday tasks — drafting, summaries, quick questions.

ROMChat Standard

More powerful. Reach for it on complex, detailed, or high-stakes work.

Switch anytime using the Fast / Standard buttons above the message box. New chats start on Fast.

Can I create diagrams, web pages, or code?

Yes. ROMChat can generate things like flowcharts, simple web pages, and code, and show them in a live preview next to your chat.

  1. Turn on Artifacts using the + button.
  2. Ask for what you want — for example, “Create a flowchart of our onboarding process” or “Build a simple web page with a contact form.”
Tip: Artifacts only appears when you ask for something it can build (like a diagram or a page). A normal question just gives you a normal answer.

Can I have a private, one-off chat?

Yes. Use Temporary Chat for a conversation you don't want kept in your history — handy for quick, throwaway questions. Temporary chats aren't saved.

Are my conversations saved?

Yes. Your past conversations are listed in the left sidebar, so you can return to them any time. (Temporary chats are the exception — those aren't saved.)

Good to know

  • ROMChat can't access ROMTech's internal systems, browse the internet, or send messages.
  • For HR, Legal, IT support, or a security concern, contact those teams directly rather than relying on the assistant.
