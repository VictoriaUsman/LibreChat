ROMTech AI — Help & FAQ

Everything you need to get started, in plain language.

New here? ROMTech AI is your internal AI assistant for everyday work — drafting, summarizing, analysis, answering questions, and more. This page covers the common questions. If you're stuck, just ask the assistant directly in a chat.

🔒 Is it safe to put sensitive information in?

Yes. ROMTech AI runs on ROMTech's approved, secure infrastructure — it's built for confidential and sensitive work. You should use it instead of public tools like ChatGPT or Claude for anything confidential, because those public tools are not approved for ROMTech information.

📄 How do I ask questions about a document?

To have the assistant read a file and answer questions about it, use File Search:

  1. Click the + button next to the message box and switch on File Search.
  2. Click the 📎 paperclip and choose Upload for File Search.
  3. Pick your file (PDF, Word, PowerPoint, Excel, or plain text).
  4. Type your question about the document and send.
💡 Turn on File Search before you upload. If it's off, the assistant may not be able to read your file. File Search covers the documents you've added in this conversation.

⚡ Which model should I use — Fast or Standard?

ROMTech AI Fast

The default. Quick and great for everyday tasks — drafting, summaries, quick questions.

ROMTech AI Standard

More powerful. Reach for it on complex, detailed, or high-stakes work.

Switch anytime using the Fast / Standard buttons above the message box. New chats start on Fast.

📎 What kinds of files can I use?

Supported: PDF, Word, PowerPoint, Excel, and plain-text files.

Not supported: images and photos (JPG, PNG, etc.).

🤔 I uploaded a document but it didn't seem to read it

  • Make sure File Search is turned on before uploading (step 1 above).
  • When attaching, choose “Upload for File Search” — not the other upload options.
  • Scanned or photo-based PDFs (no selectable text) may not be readable.
